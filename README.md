# RV32I Pipelined CPU

An individual project for building a 5-stage pipelined RV32I processor in Verilog/SystemVerilog

## Planned Features

- RV32I-style datapath
- 5-pipeline stages:
 - IF: Instruction Fetch
 - ID: Instruction Decode
 - EX: Execute
 - MEM: Memory
 - WB: Write Back
- ALU
- Register file
- Instruction decoder
- Pipeline registers
- Forwarding unit
- Hazard detection
- Branch flush logic
- Self-checking testbenches
- GTKWave waveform debugging

## Toolchain 

- Icarus Verilog
- Verilator
- GTKWave
- Yosys
- Make
